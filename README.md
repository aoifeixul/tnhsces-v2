# TNHS Computerized Enrollment System — 13I

This is the split-source version of the final 13I system.

## Files
- `index.html` — page structure/content
- `style.css` — complete styling
- `app.js` — complete application JavaScript
- `assets/tnhs-logo.png` — TNHS logo used by the interface

## Run
Keep the folder structure intact and open `index.html` in a browser.

The system uses browser `localStorage` for enrollment records and activity logs; it does not connect to a production database.
